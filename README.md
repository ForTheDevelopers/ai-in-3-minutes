## 📖 简介

AI 不是魔法，每个概念都能 3 分钟说透。

「3分钟搞懂AI」用最简洁的语言、最生活化的类比，帮你快速理解人工智能领域的核心概念：从基础原理到前沿应用，从主流模型到 Agent 工程。

**适合谁读**

- 🔰 想了解 AI 但不知从何入手的小白
- 💼 需要快速了解 AI 技术的职场人士
- 💻 想开发 AI 应用的开发者
- 🗣️ 需要向别人解释 AI 概念的技术人员

**有什么不同**

- ⏱️ 严格控制 3 分钟阅读时间
- 🏠 每个概念都有生活化类比
- 💡 强调实用性，给出可操作的建议
- 🌍 全球视角，兼顾国内外主流技术
- ⚠️ 标注时效性，AI 发展快，信息以官方为准
